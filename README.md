# 测试用例生成系统

一个基于MiniMax API的测试用例自动生成工具，支持两种运行模式。

## 功能

- 从Excel/Word文档中提取需求
- 调用MiniMax API生成测试用例
- 输出JSON和Excel格式的测试用例
- 支持两种运行模式：贪婪模式和理性模式

## 安装

1. 安装依赖：
```bash
pip install -r requirements.txt
```

2. 配置API密钥：
```bash
cp .env.example .env
# 编辑.env文件，填入你的OPENAI_API_KEY和OPENAI_BASE_URL
```

## 使用方法

### 模式1：贪婪模式 (Greed Mode)

直接读取所有文档内容并生成测试用例，无需人工干预。

```bash
python main.py --mode greed
# 或者直接运行（默认为greed模式）
python main.py
```

**适用场景**：
- 文档内容质量高，无需修改
- 需要快速批量生成测试用例
- 信任AI的提取和理解能力

### 模式2：理性模式 (Rationality Mode)

从Excel文件按行提取需求（每行作为一条独立需求），逐条显示并由用户确认或修改后再生成测试用例。

```bash
python main.py --mode rationality
```

**工作原理**：
- 自动读取 `input/` 目录中的Excel文件
- 将每一行（除表头外）作为一条独立需求
- 保留行的所有列信息（功能大类、功能子类、当前基线、期望情况等）
- 逐条显示需求，等待用户确认

**交互操作**：
- 输入 `y` 或直接回车：确认当前需求
- 输入 `e`：编辑当前需求（输入新内容，以 `END` 结束）
- 输入 `s`：跳过当前需求
- 输入 `q`：退出并使用已确认的需求

**适用场景**：
- 需要精确控制每条需求
- Excel表格中每行是一个独立的功能需求
- 需要人工审核和筛选需求
- 希望过滤或修改某些需求

**注意**：理性模式需要交互式终端环境，必须在命令行中手动运行。

## 输出文件

- `test_cases_output.json` - JSON格式的测试用例
- `test_cases_output_YYYYMMDD_HHMMSS.xlsx` - Excel格式的测试用例
- `confirmed_requirements.json` - (仅rationality模式) 确认的需求列表

## 项目结构

```
├── input/                          # 输入文档目录（Excel/Word）
├── outputformat/                   # Excel模板目录
├── minimax_client.py              # MiniMax API客户端
├── test_case_generator.py         # 测试用例生成器
├── file_reader.py                 # 文件读取模块
├── excel_writer.py                # Excel输出模块
├── requirement_manager.py         # 需求管理模块（rationality模式）
├── main.py                        # 主程序入口
├── requirements.txt               # 依赖包
└── .env.example                   # 环境变量示例
```

## 进度显示

程序会实时显示API调用进度：
- 动态进度条显示等待时间
- 自动重试机制（遇到529错误）
- 详细的日志输出

## 注意事项

- 将输入文档放在 `input/` 目录下
- 支持的文档格式：`.xlsx`, `.xls`, `.docx`, `.doc`
- API调用可能需要30-60秒，请耐心等待
- 理性模式下，确认的需求会保存到 `confirmed_requirements.json`
