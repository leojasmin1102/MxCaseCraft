# CELAS1 对标基线

## 关键语义

`CELAS1` 是引用 `PELAS` 属性的标量弹簧，连接两个指定自由度，或连接一个指定自由度和地端。`C1/C2` 对应 GRID 的位移坐标系 `CD` 分量；标量弹簧没有几何方向。地端通过连接端的 GRID 留空、对应分量留空或为 0 表示。两端 GRID 如均存在，优先使用重合节点，避免非重合节点产生非物理力矩。

静力单元力基本关系为：`F = K × (u1 - u2)`；单元应变能为：`E = 0.5 × K × (u1 - u2)²`。

## 推荐正常用例

| 编号 | 目的 | 推荐参数与预期 |
| --- | --- | --- |
| T01 | 单端接地 | `K=1e6 N/m`，`F=1000 N`；`U=0.001 m`，单元力绝对值 `1000 N`，应变能 `0.5 J`。 |
| T02 | 两节点连接 | 与 T01 同刚度与载荷；固定一端、另一端仅 X 向自由；加载端位移 `0.001 m`，固定端反力 `-1000 N`。 |
| T03 | PID 映射 | 分别使用 `K=1e6` 与 `K=2e6`；加载端位移应分别为 `0.001 m`、`0.0005 m`。 |
| T04 | 分量选择 | 平移 `C=2` 时 `Uy=0.001 m`；转动 `C=4` 且 `Kθ=1e6 N·m/rad`、`M=1000 N·m` 时 `Rx=0.001 rad`。 |
| T05 | 并联装配 | `K1=1e6`、`K2=2e6`、`F=1000 N`；位移 `0.000333333333 m`，分力 `333.333333/666.666667 N`。 |
| T06 | 串联装配 | `K1=1e6`、`K2=2e6`、`F=1000 N`；中间位移 `0.001 m`，加载端位移 `0.0015 m`，总能量 `0.75 J`。 |
| T07 | CD 坐标系 | 局部 X 对应全局 Y；连接 `C=1` 并沿局部 X 载荷；应得到全局 `Uy=0.001 m`、`Ux≈0`。 |
| T08 | 导入导出 | BDF 导入后再导出；EID、PID、连接分量、K、载荷、约束语义等价，T01 地端留空不变。 |
| T09 | 模态 | `m=10 kg`、`K=1e6 N/m`；一阶频率 `√(K/m)/(2π)=50.3292121 Hz`。 |
| T10 | 频响与 GE | `GE=0.02`，在 T09 频率处、`F=1000 N`；位移幅值 `0.05 m`，相位约 `-90°`。 |
| T11 | 端点交换 | 交换 `G1/C1`、`G2/C2` 后，位移、反力和能量不变；单元力符号反向。 |

## 推荐异常用例

| 编号 | 输入 | 预期诊断 |
| --- | --- | --- |
| D01 | PID 未定义 | 报告 PELAS 属性不存在，拒绝求解。 |
| D02 | GRID 未定义 | 报告节点不存在，拒绝求解。 |
| D03 | C=7 | 报告自由度分量范围非法。 |
| D04 | 两端完全相同 | 报告两个连接端不能相同。 |
| D05 | 地端 GRID 留空但分量为 1 | 报告地端分量必须为空或为 0。 |
| D06 | EID 重复 | 报告单元编号重复。 |
| D07 | K=0 或负值 | 报告零刚度、负刚度或不稳定性；不得静默计算。 |
| D08 | 欠约束 | 报告刚体模态、奇异矩阵或未约束自由度。 |
